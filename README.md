# Compras Estratégicas CAF
Sitio estático listo para GitHub Pages.

## Fuentes
- **Fechas:** cantidades y pipeline estratégico de tiendas. Los registros `X 30`, `X 60`, etc. se interpretan como 30/60 tiendas.
- **Data:** CAPEX y matriz presupuestaria.
- **Resumen estratégico:** objetivo, pilares, estrategias, acciones, valor para el negocio y métricas.
- **Plan:** responsables de proyectos cuando existe coincidencia con el proyecto estratégico.

## Publicar
Subir `index.html`, `styles.css`, `app.js` y `data.js` a la raíz de la rama `main`. En Settings → Pages usar `Deploy from a branch`, `main`, `/(root)`.
