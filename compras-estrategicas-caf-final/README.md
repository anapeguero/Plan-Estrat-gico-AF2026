# Compras Estratégicas CAF — versión final

Versión preparada para GitHub Pages.

## Archivos
- `index.html`: versión autónoma; contiene una copia integrada de CSS, datos y JavaScript para evitar fallos de carga en GitHub Pages.
- `styles.css`: copia editable de estilos.
- `data.js`: copia editable de los datos.
- `app.js`: copia editable de la lógica.

GitHub Pages solo necesita `index.html` para funcionar. Los otros archivos se incluyen para facilitar mantenimiento y futuras ediciones.
